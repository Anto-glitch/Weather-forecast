#TECH STACK 
In the table below there are all technologies used in Weather forecast project

##1.Core 
* **Language:** TypeScript (v6.x)
* **Framework:** React Native (Expo SDK 57)
* **Enviroment:** Node.js (v20+ LTS)
* **Package menager:** npm
* **Router:** expo-router
* **CI:** github-workflows

##2.Crucial dependecies
