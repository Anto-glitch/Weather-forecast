# Weather-forecast
Simple mobile app giving a precise short term weather forecast for the Central Europe
from Open-Meteo API according to client gps location or chosen city

## Features
- temperature
- wind velocity
- rain amount
- cloud 
- sunset/sunrise hours
- UV index
